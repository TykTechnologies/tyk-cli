## Intent
As an API operator I can manage access policies — list, retrieve, apply idempotently, delete, and scaffold new policy files — so that I can control which API products clients can consume

## Context
- Level: Stakeholder
- Component: policy
- Type: guarantee
- Category: functional
- Status: approved
- Assurance: B

## Rationale
Policies gate API access and SLA enforcement. Operators must be able to create and reconcile policies programmatically as part of the same workflow that manages APIs.
